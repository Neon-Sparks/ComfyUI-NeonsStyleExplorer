# Screenshots

Drop the manual's screenshots here and link them from `MANUAL.md`.

The manual marks each spot with `[screenshot: ...]` describing what to capture:

1. `node.png` — the whole node: a style selected, the panel showing a preview,
   the composed prompt readout at the bottom.
2. `panel.png` — close-up of the panel: preview image, name and family chip,
   shot strip, button row.
3. `browser.png` — the full browser: banner, toolbar, a grid of cards with
   previews (fill some previews first, an empty grid sells nothing).
4. `card.png` — one card hovered, showing the star, the delete cross and Use.
5. `crawl.png` — the node set up for a crawl run: crawl on, roll_scope on
   missing preview, auto_gallery on every.
6. `catalogs.png` — the catalog picker open with two or three named catalogs
   and their preview counts.
7. `editor.png` — the editor open on an existing style.

Keep them PNG, 2x if your display allows, and crop tight to the node or panel
rather than screenshotting the whole ComfyUI window.
